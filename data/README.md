# Dataset: MGNREGA district panel for the ABPS deletion study (Team ByteMe)

**Source.** MGNREGA MIS (NREGASoft), Ministry of Rural Development, national report index
`https://mnregaweb4.dord.gov.in/netnregarep/MISreport4.aspx`. We selected State = ALL and drilled
down to district level for each financial year (FY). Pulled on 29 Oct 2026. The index page is behind
an arithmetic captcha, which a team member solved by hand. Public, district-level data; no personal
records.

**Size.** 15 report-year tables · 1.7 MB of raw JSON · about 34 states/UTs × about 700–750 districts per year.

## Folders

| Folder | Contents |
|---|---|
| `raw/` | `mgnrega_mis_extract_part1-3.json`: every MIS table exactly as served (cell text kept verbatim), one record per report × FY, with fetch timestamps. This is the only input the notebook needs |
| `reference/` | `loksabha_AU294_2025-02-04_active_worker_deletions.csv`: state-wise active-worker deletions for FY2022–23 and FY2023–24, from Lok Sabha Unstarred Question 294 (4 Feb 2025). Used as a cross-check |
| `interim/` | Tidy district tables parsed from `raw/`, one per report (generated by the notebook) |
| `processed/` | Analysis panels (generated): `deletions_district_panel.csv`, `stage0_analysis_frame_2020-2021.csv` |

## Reports used

| MIS report | Years | Behaviour across FY selection | Used for |
|---|---|---|---|
| R1.2.3 Account Opened and Amount Disbursed through Bank/Post Office | FY2018–19 to FY2021–22 | Year-specific | Exposure (account mix); wage denominator |
| Deleted Job Card/Applicants with A/C No, Photos Uploaded | FY2018–19 to FY2022–23 | Cumulative stock as of the FY | Outcome (annual deletions = year-on-year change) |
| Aadhar Based Payment Report | FY2018–19 to FY2021–22 | Year-specific (only 4 states from FY2022–23) | Pre-mandate ABPS readiness |
| Aadhaar Status with NPCI Mapper | Current snapshot | Not year-specific | Current readiness (after the deletions) |
| Aadhaar Authentication Status Report | Current snapshot | Not year-specific | Current ABPS-eligible count |

## Key variables

| Variable | Definition |
|---|---|
| `expo` | (post-office accounts + joint bank accounts) ÷ all worker accounts, FY2020–21 |
| `joint_share`, `po_share` | Joint (bank + post office) and post-office shares of all worker accounts |
| `high` | 1 if the district is in the top decile of `expo` within its state (states with ≥ 5 districts) |
| `abps_share@FY` | ABPS processed amount ÷ total wages paid to accounts in that FY (rows > 1.05 excluded and counted) |
| `worker_deletions` | Workers tagged deleted at the end of FY t minus at the end of FY t−1 |
| `stock_start` | Registered minus deleted workers at the end of FY t−1 |
| `del_rate_per_1000` | 1000 × `worker_deletions` ÷ `stock_start` |
| `neg_flag` | Net deletions < 0 (restorations or record revisions); excluded from the main outcome and counted |

## Handling rules
Blank cells stay missing and true zeros stay zero. No outcome is imputed. In every table, the
district rows sum exactly to each state's printed total (0 mismatches). Districts created by later
splits are not imputed; they drop out of the year-to-year match and are listed in
`outputs/tables/deletions_unmatched_districts.csv`.
